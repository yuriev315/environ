# Python 版本选择

- 本库提供 **CPython 3.10.11** 与 **CPython 3.12.10** 两棵独立的树，两者的 wheel 不能混用。
- 这两个版本是各自版本线最后带 Windows 安装程序的版本；之后的补丁版本只发布源码。
- 3.10 已于 2026-10 结束官方支持，但一些较老的库（如部分 TensorFlow、GPflow 组合）在 3.10 上更稳；新项目优先用 3.12。
- 不要把这些 wheel 装进 3.13 或 3.14：大多数二进制 wheel 带 `cp310` / `cp312` 标签，pip 会拒绝。
- 每棵树内，同一个包在所有组中只用一个版本；唯一例外是 `scikit-base`：信号补充（pykalman 0.11.2 需要 <0.14）用 0.13.2，`16_timeseries_quant` 组（sktime）用 1.0.2，两者在不同的 `.venv` 中。
- 版本取 2026-08-01 之前发布的稳定版（补充包取 2026-10-31 之前），不选预发布版。
